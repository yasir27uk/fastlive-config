# FastLive source configuration

Published automatically by the FastLive Source Guardian. Do not edit by hand: changes are overwritten.

- `config.json`: the current channel-source configuration that FastLive apps download.
- `config.json.sig`: its ECDSA P-256 signature. Apps reject any configuration that does not verify.
- `versions/`: every published version, with signatures. `history.json`: what changed and why.
- [Privacy policy](https://yasir27uk.github.io/fastlive-config/privacy.html)
